## Compact footers and editing the latest question

- Model, thinking level, timestamp, and a small two-page Copy icon now sit below each assistant answer.
- Long questions stay compact with Show more/Show less; their full text is retained.
- Click the pencil on the latest question, revise it in the composer, and Send to replace its answer.
- Cancel restores your previous draft. Validation failures or cancelled send confirmations leave the original question and answer intact.
- Missing attachments must be re-attached or explicitly removed. Local check records are preserved and stale Retry actions are rejected.

Install `qgis_ai_copilot-0.4.1-alpha.zip` using QGIS **Plugins → Manage and Install Plugins → Install from ZIP**. This is an experimental GitHub release; the accompanying checksum verifies the installable ZIP. Responses Activity, immediate Stop, image/PDF attachments, and the longer inactivity timeout remain available.
